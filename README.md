# Cisco-TFTP-Config# Cisco Config Generator

ابزاری برای ساخت خودکار فایل کانفیگ تلفن‌های Cisco IP Phone روی سرور TFTP.

تلفن‌های سیسکو موقع بوت، فایلی به نام `SEP<MAC>.cnf.xml` را از TFTP می‌گیرند
(مثلاً `SEP001122334455.cnf.xml`). این ابزار یک فایل نمونه از پوشه‌ی مدل تلفن
برمی‌دارد، مک‌آدرس داخل آن را با مک‌آدرس تلفن جدید عوض می‌کند و فایل جدید را
کنار همان نمونه ذخیره می‌کند.

## پیش‌نیاز

- Python نسخه‌ی ۳.۶ یا بالاتر
- هیچ پکیج خارجی لازم نیست (فقط کتابخانه‌ی استاندارد پایتون)
- حالت گرافیکی به `tkinter` نیاز دارد. روی ویندوز و مک همراه پایتون نصب است.
  روی لینوکس (Debian/Ubuntu): `sudo apt install python3-tk`

## ساختار پوشه‌ی TFTP

هر مدل تلفن یک پوشه است و داخل آن یک فایل نمونه‌ی `SEP*.cnf` یا `SEP*.cnf.xml` قرار دارد:

```
tftp/
├── CP-7945G/
│   └── SEP001122AABBCC.cnf.xml    <- فایل نمونه
├── CP-8841/
│   └── SEP00AABBCCDDEE.cnf.xml
└── ...
```

## اجرا

### حالت گرافیکی

```
python cisco_config_tool.py
```

1. با دکمه‌ی **Browse** پوشه‌ی TFTP را انتخاب کنید (یا مسیر را تایپ کنید و **Reload** بزنید)
2. مدل تلفن را از لیست انتخاب کنید
3. فایل نمونه را انتخاب کنید (در صورت وجود چند فایل)
4. مک‌آدرس جدید را وارد کنید
5. روی **Generate Config File** بزنید

### حالت کنسولی

```
python cisco_config_tool.py --cli
python cisco_config_tool.py --cli --path D:\tftp
```

اگر `--path` داده نشود، برنامه مسیر پوشه‌ی TFTP را می‌پرسد.

## فرمت‌های قابل‌قبول مک‌آدرس

همه‌ی این‌ها معادل‌اند و به `AABBCCDDEEFF` تبدیل می‌شوند:

```
AA:BB:CC:DD:EE:FF
aa-bb-cc-dd-ee-ff
aabb.ccdd.eeff
AABBCCDDEEFF
```

مک‌آدرس باید دقیقاً ۱۲ رقم هگز (`0-9` و `A-F`) باشد، در غیر این صورت خطا داده می‌شود.

## رفتار برنامه

- جایگزینی مک‌آدرس در **محتوای فایل** و **نام فایل** انجام می‌شود و به بزرگی/کوچکی حروف حساس نیست.
- اگر فایل مقصد از قبل وجود داشته باشد، قبل از بازنویسی تأیید گرفته می‌شود.
- اگر چند فایل `SEP*` در پوشه‌ی مدل باشد، کاربر نمونه را انتخاب می‌کند.
- BOM و پایان‌خط‌های (`\r\n`) فایل نمونه حفظ می‌شود.
- اگر مک جدید با مک فایل نمونه یکی باشد، خطا داده می‌شود.
- فایل نمونه تغییر نمی‌کند؛ فقط فایل جدید ساخته می‌شود.

## مثال

ورودی:

```
نمونه:    CP-7945G/SEP001122AABBCC.cnf.xml
مک جدید:  aa-bb-cc-dd-ee-ff
```

خروجی:

```
CP-7945G/SEPAABBCCDDEEFF.cnf.xml
```

که محتوای آن همان نمونه است و همه‌ی `001122AABBCC` ها به `AABBCCDDEEFF` تبدیل شده‌اند.
